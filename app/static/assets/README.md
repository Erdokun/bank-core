Veyra home-scene assets
======================

earth-map.jpg and earth-clouds.png: Earth textures from three.js r168 examples.
Source: https://raw.githubusercontent.com/mrdoob/three.js/r168/examples/textures/planets/earth_atmos_2048.jpg
Clouds: https://raw.githubusercontent.com/mrdoob/three.js/r168/examples/textures/planets/earth_clouds_2048.png
The repository's MIT license is preserved in THREE-LICENSE.txt.
No three.js runtime is included; the renderer is native WebGL.

earth-orbit.mp4 and earth-poster.png: preserved from the project's original
Veyra Earth hero. They are the fallback when WebGL or the texture is unavailable.
The video is loaded only when the fallback is visible and animation is enabled.

Original video:
